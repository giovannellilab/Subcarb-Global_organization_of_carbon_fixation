## Overview

This repository contains the code and metadata to reproduce all analyses and figures from the paper. We systematically characterise carbon fixation pathways across 1,513 metagenomes (412 subsurface, including 242 new samples, compared with surface ocean, freshwater and soil datasets) and estimate a global continental subsurface chemolithotrophic carbon fixation rate of ~2.65 Pg C yr⁻¹.

## Repository structure

```
data/           # Raw input data (OTU tables, environmental metadata, reference files)
data_processed/ # Intermediate files generated by the scripts (empty — run scripts to populate)
scripts/        # Analysis notebooks (Python, run in order)
r_analysis/     # Network analysis notebook (R)
outputs/        # Figures and tables generated by the scripts
figures/        # Final publication figures
```

## Reproducing the analysis

Run the Python notebooks in `scripts/` in order, then the R notebook in `r_analysis/`:

1. `01_prepare_integrated_dataset.ipynb` — integrates OTU tables and sample metadata
2. `02_samples_geochemistry.ipynb` — geochemical characterisation and water type classification
3. `03_broad_functionnal_analysis.ipynb` — broad functional diversity analysis
4. `04_carbon_fixation_analysis.ipynb` — carbon fixation pathway analysis
5. `05_correlation_env.ipynb` — correlations with environmental variables
6. `06_carbon_fixation_rates.ipynb` — global carbon fixation rate estimation
7. `07_sequencing_depth_bias_check.ipynb` — sequencing depth bias assessment
8. `r_analysis/network_analysis_r.ipynb` — co-occurrence network analysis
